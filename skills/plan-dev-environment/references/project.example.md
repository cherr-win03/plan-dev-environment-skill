# 프로젝트 위치 안내 (양식)

이 파일을 복사해 `project-<이름>.md`로 저장하고 프로젝트마다 채운다. 상태의 증거가 아니라 "어디를 먼저 볼지" 안내다. 현재 값은 인계 문서와 저장소에서 확인한다.

- 저장소와 기본 브랜치: 예) `org/app`, main에는 PR로만 병합
- 통합 방식: 예) PR(main 병합이 곧 배포, 팀 저장소) / main 직접(개인 저장소, 배포는 따로) — release-gates.md 0절
- 배포 방식: 예) main 병합이 자동 배포 / 병합 뒤 배포 전용 체크아웃에서 손으로 배포
- 먼저 읽을 것: 예) 인계 문서(현재 담당·운영 버전·남은 일), 운영 규칙(권한·보존·배포)
- 진행 기록 위치: 예) `docs/progress.md`
- 세션·역할: 예) 팀장, 부팀장(리뷰·조율), 디자인. 현재 담당은 인계 문서에.
- 사람만 할 수 있는 일: 예) 로그인, 결제·구독, 서명, 사용자 약속 문구 변경, 실제 외부 발송
- 고정 주의: 예) 정책 해시가 바뀌면 전원 재동의, SQL은 운영 엔진 로컬판으로 확인, 특정 지점보다 앞으로 롤백 금지
- 사용자 우선순위: 예) 처음 쓰는 사람도 쉽게
